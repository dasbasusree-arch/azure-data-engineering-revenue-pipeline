
# Azure Data Engineering – Revenue Pipeline

## Project Overview

This is a hands-on Data Engineering project that simulates
a company's order, payment and refund data.

The objective is to build a data pipeline that processes
business data and calculates accurate daily revenue.

## Business Problem

A company receives orders, payments and refunds from
multiple sources.

The data may contain:
- Duplicate records
- Missing values
- Invalid amounts
- Cancelled orders
- Late-arriving refunds

The pipeline should handle these issues and produce
reliable daily revenue reports.

## Dataset

The project will use four datasets:

1. Orders
2. Order Items
3. Payments
4. Refunds

## Technology Stack

- SQL
- Python
- Git and GitHub

Planned extensions:
- Azure Data Factory
- Azure Data Lake Storage
- Azure Databricks
- PySpark
- Delta Lake

## Expected Output

A daily revenue report containing:

- Business date
- Gross revenue
- Refund amount
- Net revenue
